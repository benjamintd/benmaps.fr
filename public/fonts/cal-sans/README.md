# Cal Sans

Cal Sans v2.003 is Benmaps' default interface font. These unmodified variable
WOFF2 files are the upstream product (`calsans-cossui`) cut, with weights
400–700, automatic optical sizing and separately drawn italics:

- [Upright font](https://github.com/calcom/sans/blob/v2.003/fonts/calsans-cossui/CalSansVF.woff2)
- [Italic font](https://github.com/calcom/sans/blob/v2.003/fonts/calsans-cossui/CalSansVF-Italic.woff2)

Copyright 2021 The Cal Sans Project Authors. Released under the SIL Open Font
License 1.1; the complete upstream notice is retained in `OFL.txt`. Outlines,
internal names and copyright records are unchanged.

Clair serves the map's Cal Sans Text UI faces and Noto fallbacks separately.
