# Commissioner

`Commissioner-Variable.woff2` is the existing Benmaps interface font, retained
unchanged from the former `@clair-maps/style` 0.5.6 archive. It is a WOFF2 format
conversion of the [upstream Commissioner variable font](https://github.com/google/fonts/tree/main/ofl/commissioner),
with outlines and copyright/name records retained. The complete SIL Open Font
License 1.1 and copyright notice are in [OFL.txt](OFL.txt).

SHA-256: `5462918e946a1320d5da7cd2ac472ca698b4f2cff3ee9694a7aa7980f44e1c98`.

Only the interface font is hosted here. Clair serves the map's fonts and sprites.
